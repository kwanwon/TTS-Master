AI 마스터 (TTS 컨트롤)

서킷 인터벌, 릴레이 미트, 실전 스파링부터 현장 맞춤형 AI 한국어/영어 코칭 음원 생성까지 단 하나로 완벽하게 통제합니다.

⚡ 사용자 기기를 감지하고 있습니다...
🪟 Windows 1초 간편 설치 프로그램 (.exe) 🍎 Mac용 다운로드 (.zip)
📦 Windows 무설치 포터블 압축본이 필요하신가요? (AIMaster_TTS_Windows.zip)

공식 GitHub 릴리즈 | Windows 10/11 & macOS (Apple Silicon / Intel M시리즈 호환) 지원

🚀 1분 초간단 설치 & 실행 가이드

다운로드 후 설치 과정 없이 바로 압축만 풀어서 실행할 수 있습니다. 운영체제별 보안 통과 방법을 확인하세요.

1

설치 프로그램(AIMaster_TTS_Setup.exe) 다운로드 및 실행

상단의 [🪟 Windows 1초 간편 설치 프로그램] 버튼을 눌러 다운로드한 AIMaster_TTS_Setup.exe를 실행합니다.

💡 파란색 [Windows의 PC 보호] 알림이 뜰 때:
마이크로소프트의 외부 프로그램 기본 알림입니다. 창 중간의 [추가 정보]를 누른 후 나타나는 [실행] 버튼을 누르면 설치 마법사가 열립니다.
2

[다음] 클릭하여 설치 완료 (바탕화면 아이콘 자동 생성)

설치 마법사에서 [다음]을 누르면 설치가 완료되며, 바탕화면에 AI 마스터 사자 로고 바로가기 아이콘이 자동으로 생성됩니다.

✨ 오디오 엔진(ffmpeg)이 자동 번들 설치되므로, 윈도우 환경에서도 신호음뿐만 아니라 모든 한국어/영어 음성 코칭이 즉시 우렁차게 재생됩니다.
3

시리얼 번호 입력 및 시작

바탕화면의 바로가기를 실행한 후 발급받으신 라이선스 시리얼 번호를 입력창에 넣고 [인증] 버튼을 누르면 즉시 모든 기능이 활성화됩니다!

✨ 한 번 등록된 시리얼은 안전하게 로컬에 캐시되어, 다음 실행부터는 기다림 없이 0.001초 만에 바로 프로그램이 열립니다. 체육관 인터넷이 끊겨도 7일간 오프라인 작동이 보장됩니다.
1

다운로드 및 압축 풀기

상단의 [🍎 Mac용 다운로드] 버튼을 눌러 AIMaster_TTS_Mac.zip을 다운로드한 후 더블 클릭하여 압축을 풉니다.

2

앱 실행 및 Gatekeeper 보안 알림 통과

압축 해제된 AIMaster_TTS_Mac.app을 [응용 프로그램] 폴더 또는 바탕화면에 두고 실행합니다.

💡 '확인되지 않은 개발자' 알림이 뜰 때:
앱 아이콘 위에서 마우스 우클릭(또는 Control + 클릭) ➔ [열기] ➔ [열기]를 누르시면 첫 1회 보안 허용 후 영구적으로 자유롭게 실행됩니다.
3

시리얼 번호 입력 및 시작

프로그램 시작 창에 발급받으신 라이선스 시리얼 번호를 입력하고 확인을 누르면 바로 훈련 통제 화면으로 진입합니다.

🔑 Google Gemini 무료 API Key 발급 3분 가이드

AI 마스터는 구글의 최신 초고속 모델(Gemini 2.5 Flash / 3.1 Flash Lite)을 사용하여 맞춤형 훈련 대본을 생성합니다. 구글 계정만 있으면 매달 완전 무료(비용 0원)로 무제한 사용하실 수 있습니다.

💡

왜 Gemini 무료 모델을 사용하나요?

구글 AI 스튜디오는 무료 티어(Free Tier)를 기본 제공합니다. 체육관에서 매일 수십 회 이상 대본을 자동 생성해도 무료 할당량(분당 15회, 일 1,500회) 안에서 충분히 무료로 사용하실 수 있습니다.

1

Google AI Studio 사이트 접속 및 구글 로그인

구글 공식 개발자 사이트인 Google AI Studio에 접속한 후, 평소 사용하시는 구글 계정으로 로그인합니다.

🌐 Google AI Studio 바로가기 (aistudio.google.com) ↗
2

[Create API key] 버튼 클릭

화면 상단 또는 중앙에 보이는 파란색 [Create API key] 버튼을 클릭합니다.

  • 팝업이 뜨면 "Create API key in new project"(새 프로젝트에서 키 생성)를 선택합니다.
  • 약 3초 뒤 영문과 숫자가 섞인 긴 키(예: AIzaSyD...)가 생성됩니다.
3

생성된 키 복사 (Copy)

화면에 나타난 API 키 옆의 [Copy](복사) 버튼을 클릭하여 클립보드에 복사합니다.

🔒 보안 안내: API 키는 비밀번호와 같으므로 타인에게 공유하지 마시고 내 컴퓨터 프로그램에만 등록하세요.
4

AI 마스터 프로그램에 등록하기

AI 마스터 프로그램 상단의 [⚙️ AI·수련자료 통합 설정] 버튼을 누르고, 복사한 키를 붙여넣은 뒤 [🔍 연결 확인] ➔ [저장]을 클릭합니다.

✨ 한 번만 저장해 두면 프로그램의 모든 훈련 탭(서킷, 릴레이 미트, 스파링 등)에서 영구적으로 자유롭게 대본 자동 생성이 작동합니다!
🖥️ 프로그램 UI 상세 화면 구성 가이드

AI 마스터의 강력한 기능들이 직관적인 탭과 컨트롤 바로 배치되어 있습니다. 화면의 주요 구성 요소를 한눈에 파악하세요.

⚙️
상단 공통 바

통합 설정 & 원클릭 제어

• ⚙️ AI·수련자료 통합 설정: Gemini API 키, 구글 드라이브 문서 링크, 체육관 월간 수련계획표 파일 등록.
• 📖 온라인 설명서: 웹 매뉴얼 즉시 호출.
• 🔄 최신 업데이트: 클릭 한 번으로 새 버전 확인 및 자동 갱신.

⏱️
핵심 훈련 모드 1

서킷 인터벌 트레이닝

• 스포츠 과학 4대 체력(순발력, 민첩성, 스피드, 협응력) 종목 자동 분배.
• "1콤보에서 3콤보까지 해줘"처럼 원하는 콤보 수를 자연어로 주문 가능.
• 운동 시간, 휴식 시간, 라운드 디지털 카운트다운 타이머 완벽 통제.

🥊
핵심 훈련 모드 2

릴레이 미트 순환 대련

• 1:1 모드: 플레이어 1명과 1번 보조자 집중 미트 훈련 (좌우/양쪽 연습 시 오른쪽/왼쪽 분리 세트 자동 생성).
• 1:2 / 1:3 모드: 플레이어가 여러 보조자를 순환 타격하는 고강도 순환 시스템.

⚡
핵심 훈련 모드 3

실전 스파링 반응 타격

• 불규칙한 랜덤 간격으로 터져 나오는 실전 타격 구령.
• 신호음(휘슬/비프) 전에 선수들이 미리 움직이지 않도록 구령 타이밍 완벽 동기화.
• 실제 대련 득점 콤보 및 받아차기 카운터 자동화.

🏃
보조 훈련 모드 4

셔틀런 & 준비 운동(Warm-up)

• 국가대표 체력 평가용 20m 왕복달리기(셔틀런) 레벨별 비프 음원 자동 생성.
• 수련 시작 전 부상 방지 관절 회전 및 동적 스트레칭 가이드 음성.

🎵
사운드 엔진

음향 & 배경음악(BGM) 믹서

• 훈련 중 신나는 배경음악 자동 재생 및 음악 재생목록 지원.
• 오디오 덕킹(Ducking): 사범님 음성이나 신호음이 나올 때 음악 볼륨이 자동으로 줄어들어 목소리가 또렷하게 들림.

🥋 실전 훈련 생성 & 실행 순서 (4단계 워크플로우)

체육관 현장에서 관장님과 사범님이 수업을 준비하고 시작하는 표준 순서입니다.

1

[1단계] 훈련 모드 선택

오늘 수업할 훈련 종류(서킷 인터벌, 릴레이 미트, 스파링 반응 등) 탭을 선택합니다.

2

[2단계] 할 운동 요구사항 입력 ➔ AI 즉석 템플릿 생성

상단 보라색 박스의 입력창에 원하는 내용을 자연어로 적습니다.
예: "1콤보에서 3콤보까지만 해줘. 협응력을 키울 수 있는 종목에 발바꿔 찍어차기 3회, 나래차기, 하단뒤돌려차기 분배해줘"
우측의 [✨ 요구사항으로 즉석 템플릿 생성] 버튼을 누르면 AI가 테마 제목, 사전 설명 방송, 콤보별 기술과 영어 구령, 지도 팁을 자동으로 완성합니다.

3

[3단계] 한국어 동작 자유 수정 ➔ 다시 생성 (선택 사항)

생성된 대본에서 횟수나 동작을 바꾸고 싶다면 대본 창에서 한글만 편하게 수정하세요.
수정 후 [🔄 수정한 한글로 영어·설명 다시 생성] 버튼을 누르면, 수정한 동작에 맞춰 현장 영어 구령과 사전 설명이 다시 자동으로 일치됩니다!

4

[4단계] 타이머 설정 후 [▶ 훈련 시작] 클릭!

운동 시간(초), 휴식 시간(초), 세트 수를 조절한 뒤 우측 하단의 [▶ 훈련 시작] 버튼을 누릅니다.
블루투스 스피커를 통해 당당한 사범님 목소리로 사전 설명 방송이 나오고, 카운트다운 휘슬과 함께 완벽한 훈련이 진행됩니다.

❓ 자주 묻는 질문 (FAQ)

Q. 인터넷이 연결되지 않은 곳에서도 작동하나요?

네! 최초 1회 시리얼 번호 등록 후에는 안전한 로컬 캐시를 사용하므로 인터넷 연결이 없거나 신호가 약한 지하 수련장에서도 7일간 완벽하게 오프라인 구동됩니다.

Q. 시리얼 인증 시 오류가 나거나 반응이 느려요.

클라우드 라이선스 서버가 최초 실행 시 깨어나는 데 약 10~20초 정도 걸릴 수 있습니다. 한 번만 정상 인증되면 다음 실행부터는 0.001초 만에 즉시 열리니 잠시만 기다려 주세요.

Q. 도장 자체 수련계획표 문서를 연동해서 대본을 만들 수 있나요?

네! 상단 [⚙️ AI·수련자료 통합 설정]에서 관장님의 구글 드라이브 문서 공유 링크나 내 컴퓨터의 텍스트 파일(.txt, .docx, .md)을 등록해 두시면, AI가 해당 문서를 읽고 체육관 진도에 딱 맞는 훈련을 자동으로 생성합니다.
