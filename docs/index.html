AI 마스터 (TTS 컨트롤)

서킷 인터벌, 릴레이 미트, 실전 스파링부터 현장 맞춤형 AI 한국어/영어 코칭 음원 생성까지 단 하나로 완벽하게 통제합니다.

⚡ 사용자 기기를 감지하고 있습니다...
🪟 Windows용 다운로드 (v1.9.14) 🍎 Mac용 다운로드 (v1.9.14)

최신 공식 릴리즈 | Windows 10/11 & macOS (Apple Silicon / Intel) 지원

🚀 1분 초간단 설치 & 실행 가이드
1

다운로드 및 압축 풀기

상단의 [🪟 Windows용 다운로드] 버튼을 눌러 AIMaster_TTS_Windows.zip 파일을 다운로드한 뒤, 원하는 폴더(예: 바탕화면)에 압축을 풉니다.

2

프로그램 실행 및 보안 안내 통과

압축 해제된 폴더 안의 AIMaster_TTS_Windows.exe 파일을 더블 클릭하여 실행합니다.

💡 'Windows의 PC 보호' (파란색 창) 알림이 뜰 때:
당황하지 마시고 창 중간의 [추가 정보]를 누른 후 나타나는 [실행] 버튼을 누르시면 정상적으로 실행됩니다.
3

시리얼 번호 입력 및 시작

프로그램이 켜지면 안내받으신 라이선스 시리얼 번호를 입력창에 넣고 [인증] 버튼을 누르면 즉시 모든 기능이 활성화됩니다!

✨ 한 번 등록된 시리얼은 안전하게 캐시 저장되어, 다음 실행부터는 기다림 없이 0.001초 만에 바로 프로그램이 열립니다.
1

다운로드 및 압축 풀기

상단의 [🍎 Mac용 다운로드] 버튼을 눌러 AIMaster_TTS_Mac.zip을 다운로드한 후, 더블 클릭하여 압축을 풉니다.

2

앱 실행 및 Gatekeeper 보안 알림 통과

압축 해제된 AIMaster_TTS_Mac.app을 [응용 프로그램] 폴더 또는 바탕화면에 두고 실행합니다.

💡 '확인되지 않은 개발자' 알림이 뜰 때:
앱 아이콘 위에서 마우스 우클릭(또는 Control + 클릭) ➔ [열기] ➔ [열기]를 누르시면 첫 1회 보안 허용 후 영구적으로 자유롭게 실행됩니다.
3

시리얼 번호 입력 및 시작

프로그램 시작 창에 발급받으신 라이선스 시리얼 번호를 입력하고 확인을 누르면 바로 훈련 통제 화면으로 진입합니다.

🥋 주요 핵심 기능

서킷 & 인터벌 트레이닝

실전 스파링 반응 타격

불규칙한 반응 타격 구령, 카운트다운 신호음, 음성 조기 출발 방지 동기화로 실전 대련 감각 극대화.

❓ 자주 묻는 질문 (FAQ)

Q. 인터넷이 연결되지 않은 곳에서도 작동하나요?

네! 최초 시리얼 인증 후에는 로컬 캐시를 통해 인터넷 연결이 불안정하거나 없는 수련장 환경에서도 7일간 완벽하게 오프라인 구동됩니다.

Q. AI 자동 훈련 생성 기능(Gemini)을 사용하려면 어떻게 하나요?

프로그램 상단의 [⚙️ AI·수련자료 통합 설정] 메뉴에서 무료 Gemini API Key를 입력하시면, 나만의 훈련 요청 프롬프트로 무제한 대본 생성이 가능합니다.
