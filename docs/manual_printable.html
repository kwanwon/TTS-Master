제1장. 프로그램 설치 및 시작 (1분 가이드)

1. Windows 사용자 (1초 간편 설치 프로그램)

  1. 공식 웹페이지에서 AIMaster_TTS_Setup.exe 파일을 다운로드합니다.
  2. 다운로드한 파일을 더블 클릭하여 실행합니다.
    💡 파란색 [Windows의 PC 보호] 창이 뜰 때:
    창 중간의 [추가 정보]를 클릭한 후 나타나는 [실행] 버튼을 누르면 정상적으로 설치 마법사가 실행됩니다.
  3. 설치 마법사에서 [다음]을 누르면 1초 만에 설치가 완료되며, 바탕화면에 AI 마스터 사자 로고 아이콘이 자동으로 생성됩니다.
  4. 최신 v1.9.17에는 오디오 재생 엔진(ffmpeg)이 완벽 번들링되어 있어 음성이 100% 정상 출력됩니다.

2. macOS 사용자

  1. 공식 웹페이지에서 AIMaster_TTS_Mac.zip을 다운로드하고 압축을 풉니다.
  2. 압축 해제된 AIMaster_TTS_Mac.app 아이콘 위에서 마우스 우클릭 ➔ [열기] ➔ [열기]를 누르면 Gatekeeper 보안이 통과되어 영구 실행됩니다.

3. 시리얼 라이선스 번호 등록

프로그램 첫 실행 시 나타나는 입력창에 본사에서 발급받은 라이선스 시리얼 번호를 입력하고 [인증]을 누릅니다. 한 번 인증되면 안전하게 캐시되어 다음 실행부터는 0.001초 만에 즉시 실행되며 인터넷이 없는 환경에서도 7일간 오프라인 작동합니다.

제2장. Google Gemini 무료 API Key 발급 및 연동

💰 비용 팩트 (완전 무료):
구글 AI 스튜디오(Google AI Studio)는 매달 무료 티어(Free Tier)를 제공합니다. 하루 1,500회까지 대본을 생성할 수 있어 도장에서 매일 수십 번 대본을 만들어도 비용이 0원입니다.

무료 API Key 발급 4단계 절차

  1. Google AI Studio 접속: 웹 브라우저에서 https://aistudio.google.com/app/apikey 에 접속 후 구글 계정으로 로그인합니다.
  2. [Create API key] 클릭: 화면의 파란색 [Create API key] 버튼을 누르고, 팝업에서 "Create in new project"를 선택합니다.
  3. 키 복사: 약 3초 뒤 생성된 긴 키(예: AIzaSy...) 옆의 [Copy] 버튼을 눌러 복사합니다.
  4. 프로그램에 등록: AI 마스터 프로그램 상단 [⚙️ AI·수련자료 통합 설정] 클릭 ➔ API Key 칸에 붙여넣기 ➔ [🔍 연결 확인] ➔ [저장].

제3장. 서킷 인터벌 트레이닝 완전 정복

스포츠 과학 표준 4대 체력 요소와 태권도/합기도/격투기 실전 발차기 기술을 지능적으로 결합하여 현장 맞춤형 대본을 만듭니다.

체력 요소목적 & 신체 효과대표 표준 종목연계 타격 기술
순발력 (Power)순간적인 최대 폭발력스쿼트 점프, 터크 점프, 점핑 런지점프 뒤차기, 뛰어 찍기
민첩성 (Agility)신속한 바닥 기립 및 방향 전환버피테스트, 앞구르기, 사이드 스텝앉아 뒤돌아차기, 나래차기
스피드 (Speed)초고속 발놀림 및 연속 빈도마운틴 클라이머, 빠른 발구르기빠른 연속 발차기 3~5연타
협응력 (Coordination)전신 균형, 중심축 제어 및 평형낙법 후 중심잡기, 밸런스 점프, 플랭크 로테이션발바꿔 찍어차기, 하단 뒤돌려차기

사범님 실전 추천 프롬프트 (그대로 복사 사용 가능)

"1콤보에서 3콤보까지만 해줘. 협응력을 키울 수 있는 종목에 발바꿔 찍어차기 3회, 나래차기, 하단뒤돌려차기 를 각 콤보에 분배를 해서 부탁할게."
💡 콤보별 균등 분배 원칙 (몰아넣기 방지):
여러 발차기를 나열하면 1번 콤보에 다 몰아넣지 않고, 1번 콤보(발바꿔 찍기) ➔ 2번 콤보(나래차기) ➔ 3번 콤보(하단 뒤돌려차기)로 1개씩 나누어 깔끔하게 배치합니다.

제4장. 릴레이 미트 순환 대련 완전 정복

사범님이 미트를 잡아주지 않아도, 플레이어와 보조자들이 일사불란하게 미트를 대주고 타격하도록 통제합니다.

1. 1:1 모드 (플레이어 1명 vs 보조자 1명) - 좌우 분리 세트

  • 사범님이 "양쪽", "좌우", "양발"을 요구하면, 단순 복사가 아니라 1세트는 '오른쪽', 2세트는 '왼쪽'으로 분리된 정교한 2개 세트로 자동 완성됩니다.
"플레이어 방족술 전진 허리 감아 던지기, 1번 보조자 전진 몸통차기 1회, 양쪽 연습할 수 있게 해줘."

2. 1:2 및 1:3 다자간 릴레이 모드

  • 1:2 모드: 플레이어 1명이 1번 보조자 타격 후, 신속히 2번 보조자로 이동 타격.
  • 1:3 모드: 1번, 2번, 3번 보조자가 순서대로 미트를 잡고 연속 돌파 훈련.

제5장. 실전 스파링 반응 타격 & 셔틀런

1. 실전 스파링 반응 타격

  • 불규칙 랜덤 딜레이: 1.5초~3.5초 사이 예측할 수 없는 타이밍에 구령이 발성되어 실전 대련 반사신경을 극대화합니다.
  • 조기 출발 방지 동기화: 구령 속에 "Let's go" 같은 출발 단어를 배제하여, 선수들이 반드시 카운트다운 신호음(휘슬/비프)을 듣고 움직이도록 통제합니다.

2. 20m 왕복달리기 (셔틀런) & 웜업

  • 공인 셔틀런 음원 규격에 맞춘 레벨별 음원 및 구간 비프음 지원.
  • 수련 시작 전 부상 방지를 위한 도장 맞춤형 관절 스트레칭 음성 지원.

제6장. 오디오 & BGM 사운드 제어

  • 오디오 덕킹(Audio Ducking): 훈련 중 신나는 음악이 흐르다가, 사범님 음성이나 신호음이 나오는 순간 배경음악 볼륨이 자동으로 -8dB 줄어들어 목소리가 또렷하게 전달됩니다.
  • 효과음 선택: 카운트다운(3, 2, 1 / 영어 / 한국어), 시작 휘슬, 비프, 대북음 자유 선택.

제7장. 현장 활용 팁 & 자주 묻는 질문 (FAQ)

Q. 지하 도장이라 인터넷 연결이 자주 끊깁니다. 작동하나요?
A. 네! 최초 시리얼 인증 후에는 로컬 캐시를 사용하므로 인터넷이 전혀 없어도 7일간 완벽하게 정상 구동됩니다.
Q. 블루투스 앰프 스피커 연결 팁이 있나요?
A. 노트북이나 PC에 블루투스 앰프를 연결한 뒤, 훈련 시작 10초 전에 볼륨을 맞춰두시면 현장 전체에 울려 퍼지는 압도적인 수업 분위기가 연출됩니다.
Q. 사범님이 직접 대본 한글을 수정해도 영어가 다시 맞춰지나요?
A. 네! 대본 창에서 한글 동작만 편하게 바꾼 뒤 [🔄 수정한 한글로 영어·설명 다시 생성] 버튼을 누르면, 바뀐 한글에 맞춰 영어 구령과 사전 설명이 1초 만에 다시 맞춰집니다.
